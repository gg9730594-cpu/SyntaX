# SyntaX

> Легковесный текстовый редактор с автоматической подсветкой синтаксиса Python.

**SyntaX** — это простой и удобный текстовый редактор, разработанный на Python. Благодаря интеграции с библиотекой [Pygments](https://pygments.org/), он обеспечивает точную и приятную для глаз подсветку синтаксиса при работе с кодом.

---

## 🌟 Основные возможности

* **Подсветка синтаксиса в реальном времени:** Подсветка кода Python с использованием мощностей Pygments
* **Базовые функции редактора:** Открытие, редактирование и сохранение `.py` файлов.
* **Высокая скорость работы:** Минимальное потребление ресурсов и быстрый запуск.
